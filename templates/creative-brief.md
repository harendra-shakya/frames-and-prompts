# Creative brief — copy and fill only what matters

**Outcome:** What should the audience feel, understand, or be able to do?

**Deliverable:** Image / comic sequence / storyboard / animatic / video / motion graphic / game assets / playable prototype.

**Audience and destination:** Viewer/player, platform, aspect ratio, resolution, duration or asset dimensions.

**Story or interaction:** Core premise, emotional change, playable loop or intended call to action.

**Style system:** Medium, shape/line language, color/value rules, lighting/material rules, typography, sound character. Avoid conflicting styles.

**Fixed identity/world:** Character/costume references, props, environment landmarks, camera geography, rules that must persist.

**Selected references (1–5):**

| | | | |

**Beat/shot/asset plan:** What happens, in what order, and which artifact proves the difficult part works?

**Audio/performance/interaction:** Dialogue, singing, sound effects, music, timing, controls, feedback, if applicable.

**Non-negotiables:** Hard constraints from the user (include explicit don'ts and required content).

**Quality risks:** Three likely ways this particular task could go wrong and how you will detect them.

**Validation:** Actual image inspection size, frames/transitions/playback to check, or game loop/controls to test.

**Handoff:** Output paths/URLs, inspection evidence, remaining limitations.

Before delivery, run [anti-slop](../skills/anti-slop/SKILL.md).
